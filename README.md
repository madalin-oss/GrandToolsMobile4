# Grand Tools Mobile
Исходники Android-приложения с бирюзово-тёмным интерфейсом, настраиваемыми командами, клавиатурой и плавающим окном.

## Сборка
Загрузите **содержимое** этой папки в корень GitHub-репозитория. Откройте Actions → Build Android APK → Run workflow. APK появится в Artifacts после успешной сборки.

## Использование
Откройте приложение, включите и выберите Grand Tools Keyboard в настройках Android. Разрешите показ поверх других приложений, чтобы запустить оверлей. Кнопки в клавиатуре вставляют команды в активное текстовое поле. Оверлей копирует команду в буфер обмена; вставка вручную.

Это самостоятельная стартовая версия. Автоматическое чтение игрового чата, отправка в Telegram и дополнительные функции оригинального приложения пока не реализованы.
